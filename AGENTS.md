# Руководство для Codex

Ты работаешь с **существующим проектом Arduino Constructor & Simulator**. Не начинай новый репозиторий и не переписывай работающие части без необходимости.

## Перед изменениями

1. Прочитай `README.md`, `PROJECT_SPEC.md`, `ROADMAP.md`, `ARCHITECTURE.md`.
2. Изучи актуальные каталоги и тесты, укажи цель версии.
3. Предложи короткий план и затем реализуй задачу.

## Принципы

- Универсальный конструктор: мобильные роботы, манипуляторы, автоматика, станки.
- UI, электроника, AVR и механика — отдельные тестируемые модули.
- Не подменять эмуляцию MCU JS-анимацией.
- Не выдавать статичное изображение или вращение модели за физическую симуляцию.
- Проверять совместимость библиотек конкретными скетчами.
- В документации и статусе функций не скрывать ограничения.
- Для 2WD поддержать схему L298N с аппаратно включёнными ENA/ENB, **без проводов от Arduino к этим входам**.
- Не выдумывать фактическую распиновку реального робота — она определяется соединениями проекта.

## Перед завершением задачи

Запусти `npm run typecheck`, `npm test`, `npm run build`, когда зависимости доступны. Добавь тесты для нового поведения. Если что-то не проверено, укажи явно. Не записывай секреты и токены в Git. Делай небольшие коммиты, крупные изменения — в отдельной ветке/PR.
