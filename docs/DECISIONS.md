# Архитектурные решения (ADR)

- **ADR-001, принято:** одна компонентная модель для колёсных роботов, манипуляторов и другой автоматики.
- **ADR-002, принято:** React + TypeScript + Vite — начальная оболочка интерфейса.
- **ADR-003, принято:** изображение, механическая физика, электроника и исполнение AVR — разные подсистемы.
- **ADR-004, ожидает PoC:** проверить avr8js и Arduino CLI на настоящей прошивке, GPIO и библиотеке Servo.
- **ADR-005, принято:** сначала локальный продукт, сервер и USB-помощник — отдельные этапы.
- **ADR-006, принято:** явная маркировка неподдерживаемых и приближённых функций.
