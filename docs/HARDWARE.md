# Начальная библиотека оборудования

## Робот 2WD

- Arduino UNO R3, возможен Sensor Shield V5.0.
- L298N с IN1–IN4 и двумя DC TT-моторами.
- Шасси 2WD, свободное опорное колесо.
- HC-SR04, сервопривод, позднее датчик линии/цвета и ELRS.

### ENA / ENB

Предусмотреть режим L298N, в котором ENA и ENB постоянно включены перемычками и **не подключены к GPIO Arduino**. В этом случае скетч управляет IN1–IN4, а ШИМ на входах направления не полностью эквивалентен управлению ENA/ENB. Реальные пины IN1–IN4 не задавать без проверки проводки.

### Питание

Для реальной сборки общая земля необходима для компонентов, обменивающихся сигналами. Питание сервоприводов и моторов рассчитывается отдельно; нельзя автоматически считать вывод 5V UNO достаточным. Учебная физическая модель не заменяет электрическую проверку безопасности.

## Манипулятор

- Основание, звенья, поворотные шарниры и захват.
- Сервоприводы с ограничениями диапазона, скорости и нагрузки.
- Управление прошивкой Arduino, а не анимацией от кнопки интерфейса.
