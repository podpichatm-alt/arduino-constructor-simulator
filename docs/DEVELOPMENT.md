# Руководство разработчика

## Запуск

Понадобится Node.js 22 и npm:

```bash
npm ci
npm run dev -- --host 0.0.0.0
```

## Проверка качества

```bash
npm run typecheck
npm test
npm run build
```

`package-lock.json` включён. Используйте `npm ci` локально и в CI. Для браузерных проверок установите Chromium: `npx playwright install chromium`, затем `npm run test:e2e`.

## Изменения

1. Сформулировать проверяемый сценарий.
2. Изменить доменную модель отдельно от UI, если потребуется.
3. Добавить тесты, выполнить их и сборку.
4. Обновить дорожную карту и документацию по факту.

## Исторические ограничения V0.0

Кнопки разделов работают как навигация по будущим режимам. Реального 3D-редактора, компиляции и симуляции в этой версии нет.
