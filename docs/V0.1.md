# V0.1 — интерактивный 3D-конструктор

Историческое руководство V0.1. Текущее поведение механических соединений, reparent и миграции описано в [V0.1.1](V0.1.1.md).

## Запуск в GitHub Codespaces с Android

1. Откройте репозиторий в Codespaces и переключитесь на `feature/v0.1-3d-editor` (после слияния — `main`).
2. В терминале из каталога репозитория выполните:

   ```bash
   npm ci
   npm run dev -- --host 0.0.0.0
   ```

3. Откройте вкладку **Ports**, найдите порт **5173**, нажмите **Open in Browser**. Оставьте порт приватным; достаточно вашей авторизации GitHub.
4. Откройте адрес переадресованного порта в Chrome. Для 3D нужен доступный WebGL и аппаратное ускорение.

Node.js 22+; `package-lock.json` включён. Для production-сборки: `npm run build`; локальный просмотр: `npm run preview -- --host 0.0.0.0` (порт 4173). Vite dev server предназначен для разработки.

## Редактор

- **Каталог / сборка** открывает шаблоны, поиск компонентов и список экземпляров. На телефоне панели по умолчанию скрыты; сцена не перекрывается выезжающими окнами.
- Стартовые проекты: 2WD (8 деталей) и манипулятор (11 деталей). **Новый** создаёт пустую сборку. Замена проекта требует подтверждения внутри приложения; перед ней можно экспортировать текущую сборку.
- Добавьте компонент кнопкой в каталоге; выберите его в списке или нажатием на модель.
- Выберите **Перемещение** или **Поворот** и тяните цветную ось/кольцо. Во время работы инструмента камера блокируется. При отмене касания инструмент сбрасывается, незавершённое преобразование откатывается.
- **Свойства**: имя, локальные координаты X/Y/Z в мм, углы в градусах, размеры, родитель. Мировые/локальные оси переключают направление инструмента; координаты в инспекторе всегда относительно родителя.
- Привязка инструмента: 5 мм / 15°. Числовые поля позволяют вводить более точные значения без этой привязки.
- Дублирование копирует деталь вместе с дочерними, переназначает ID и сдвигает копию на 50 мм вдоль локальной X родителя. Удаление удаляет всё выбранное поддерево.
- Назначьте другой компонент родителем, чтобы собрать свою иерархию. Циклы, отсутствующие родители и глубина больше 32 запрещены. При смене родителя локальные значения сохраняются, поэтому положение в мире может измениться.
- У платформы и шарниров в свойствах есть ползунок угла. Все дочерние звенья следуют за суставом. Это **ручная кинематика**, без приводного управления и физических сил.
- Камера: левая кнопка мыши / один палец — вращение; правая кнопка / два пальца — сдвиг; колесо / pinch — масштаб. **Сброс камеры** центрирует всю сборку; доступны ракурсы спереди, сверху и справа.
- На телефоне сначала выберите деталь, затем откройте **Свойства**; панель находится под сценой. Каталог прокручивается отдельно. Кнопки управления имеют сенсорную высоту от 44 px.

## Сохранение и формат

Автосохранение выполняется после каждого зафиксированного изменения в `localStorage`, ключ `arduino-constructor.project.v1`. При следующем открытии на том же origin восстанавливается последний проект. Закрытие панелей, камера и текущий выбор не являются частью файла проекта.

**Сохранить** записывает текущий проект вручную. **Экспорт JSON** скачивает независимую копию, **Импорт JSON** сначала проверяет файл, затем предлагает заменить сборку. Повреждённое сохранение не перезаписывается автоматически: пользователь видит причину и может явно сохранить новый проект. При ошибке localStorage используйте экспорт.

Локальное хранилище относится к браузеру и адресу сайта, а не к GitHub-репозиторию. При смене Codespace/адреса, очистке данных Chrome или использовании другого устройства нужны экспорт и импорт JSON. Сохраняйте резервные копии важных сборок.

Формат `schemaVersion: 1`:

- Проект: `id`, `name`, `templateId`, `components`.
- Экземпляр: `id`, `definitionId`, `name`, `type`, `dimensions`, `position`, `rotation`, `parentId`, `parameters.angle`, `mounts`.
- Ядро: метры и радианы, Y вверх. Локальное преобразование — позиция → Euler XYZ → поворот сустава → дочерние объекты. Масштаб модели влияет только на геометрию, а не на координаты дочерних звеньев.
- Каталог `src/domain/catalog.ts` задаёт геометрию, тип, начальные габариты, цвет, точки будущих креплений, ось и диапазон сустава. Новый компонент добавляется записью каталога, новый вид геометрии — в `PartGeometry.tsx`.
- Импорт ограничен 2 МБ, 300 деталями и 32 уровнями иерархии. Координаты ±10 м, размеры 1–2000 мм, базовые углы ±360°. Проверяются конечные числа, уникальность ID, известность типов, диапазоны суставов, нормированные оси креплений и отсутствие циклов. Неизвестные дополнительные поля отбрасываются. Старые/будущие версии схемы явно отклоняются.

## Проверки

```bash
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

В Linux без системных библиотек браузера: `npx playwright install --with-deps chromium`.

Unit-тесты проверяют шаблоны V0.0 и новые операции с проектами, валидацию, копирование/удаление и localStorage. Playwright запускает Chromium на desktop и с профилем Pixel 7: смена шаблонов, ползунки, числовые трансформации, восстановление, импорт/экспорт, ошибочные данные, выбор моделей в WebGL, камера, жесты через Chromium DevTools Protocol и перетаскивание 3D-инструментов. Снимки и trace при ошибках находятся в `test-results/` (не входят в Git).

## Ограничения

- Упрощённые геометрические модели; габариты ориентировочные. Не CAD и не гарантия совместимости физических деталей.
- Нет физических столкновений, автоматической стыковки, IK, силы приводов, проводов, компиляции C++ и эмуляции MCU. Разделы схемы, программирования и испытаний сохранены и явно обозначают будущие этапы.
- Точки креплений — сохраняемые метаданные в исходном размере; при изменении габаритов автоматически не пересчитываются. Шаблоны настраивают иерархию вручную.
- Один автоматически сохранённый проект на origin. Нет облачной синхронизации, истории отмены или миграции сторонних форматов.
- Three.js загружается отдельным модулем; первый запуск требует загрузки 3D-зависимостей. На слабых телефонах возможна сниженная частота кадров; плотность пикселей ограничена 1.75.
- Автотесты с эмуляцией мобильного Chromium не заменяют проверку реального Android GPU, многопальцевых жестов на устройстве и поведения браузера при нехватке памяти.
