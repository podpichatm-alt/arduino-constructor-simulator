# Arduino Constructor & Simulator

Универсальная инженерная платформа для сборки, подключения, программирования и симуляции Arduino-устройств: колёсные роботы, манипуляторы, механизмы и системы автоматики.

**Текущая версия: V0.1 — интерактивный 3D-конструктор.** Работают универсальный каталог, сборки 2WD и манипулятора, выбор/перемещение/поворот деталей, иерархия суставов, localStorage и JSON-обмен. Физика, электрическая симуляция и эмуляция Arduino пока не реализованы.

[Руководство V0.1: управление, Android / Codespaces, формат и ограничения](docs/V0.1.md).

## Запуск

Установите Node.js 22 и npm. Из папки проекта:

```bash
npm ci
npm run dev -- --host 0.0.0.0
```

Проверки:

```bash
npm run typecheck
npm test
npm run build
```

> В Codespaces откройте порт 5173 через вкладку Ports → Open in Browser. `package-lock.json` включён для воспроизводимых установок. Браузерные тесты: `npx playwright install chromium` и `npm run test:e2e`.

## Планируемые возможности

1. Универсальная 3D-сборка устройств из компонентов и иерархических механических связей — реализована в V0.1; автоматические крепления впереди.
2. Электрическая схема с проверкой контактов и питания.
3. Импорт, редактирование и компиляция скетчей `.ino`.
4. Фактическое исполнение совместимых AVR-прошивок (не предопределённая анимация).
5. 3D-физика: мобильные роботы, манипуляторы и виртуальные датчики.
6. Сохранение проектов и JSON-экспорт — реализованы в V0.1; загрузка программы на реальную Arduino запланирована.

## Стартовые шаблоны

- **Робот 2WD:** Arduino UNO R3, L298N, два TT-мотора, шасси, датчики.
- **Манипулятор:** Arduino UNO, сервоприводы, звенья, шарниры и захват.
